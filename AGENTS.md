# The Greatest History

Interactive world map + timeline of the most influential events from 2000 BC to AD 2000.
Design: `docs/superpowers/specs/2026-10-01-greatest-history-design.md`, and for the unified timeline `docs/superpowers/specs/2026-10-04-unified-timeline-design.md`.

## Commands

- `npm run setup` - install deps, download map assets (borders, base map, fonts), install Playwright's Chromium. Run once after cloning.
- `npm run dev` - dev server.
- `npm test` - unit tests (Vitest).
- `npm run test:e2e` - Playwright smoke tests (builds and previews the site).
- `npm run validate` - validate `data/` (also runs as part of `npm run build`).
- `npm run check-links` - verify every event's Wikipedia URL resolves.
- `npm run build` - validate, typecheck, build to `dist/`.

## Conventions

- Years are signed integers with no year zero (-44 = 44 BC, 1 = AD 1). Use helpers in `src/lib/years.ts` for any arithmetic.
- All content lives in `data/timeline/` as one kind of record, validated by `src/data/schema.ts`. Its `kind` is `state`, `period` or `moment`: a moment has no `end` year, a state or period must have one. Every entry needs a summary, a significance and a Wikipedia link. Each file only holds entries whose `start` falls in its millennium.
- A moment or period may list in `partOf` the ids of the states and periods it belongs to (a battle and the dynasty it was fought under, a war and the wider war it was part of). The card's "Part of" and "Key moments" come only from these links, never from dates and region, so link an entry only where the relationship is real. The validator checks that each id exists, is a state or period, and overlaps in time.
- `data/folded.json` maps the ids of founding moments that were folded into their state, so old links still open something.
- Views (`MapView`, `EventPanel`, `TimelineStrip`) read and write state only through `useTimeState`; they never call each other.
- Never use the em dash character anywhere, including content.
- Map assets in `public/borders`, `public/basemap`, `public/glyphs` are generated by `npm run fetch-geo` and are gitignored.
- Borders come from historical-basemaps, corrected when they are downloaded: `scripts/borderPatches.ts` replaces wrong shapes and adds missing snapshots using Cliopatria, then `src/lib/borderFixes.ts` corrects wrong labels. After editing either, re-run `npm run fetch-geo`; era bands find their territory through the names in `src/lib/eraTerritory.ts`.
- Entries in a `data/timeline/` file are sorted by `start`, then `id`. A new `state` needs its snapshot names added to `POLITIES` in `src/lib/eraTerritory.ts`, and at least one border snapshot inside its span; otherwise make it a `period`. A matching name is not enough: check that the shape it finds contains the state's capital, because the border data mislabels some polygons.
- Selecting an entry moves the map: to its place, to its territory, or to its region (`REGION_BOUNDS` in `src/theme.ts`).
- A border polygon under the wrong name is corrected in `scripts/borderPatches.ts` with `relabel` (by position, when the name alone cannot tell it from the real one) or in `src/lib/borderFixes.ts` (by name).
- `scripts/fetch-basemap.ts` removes the redundant points along straight edges of the land shapes; without that MapLibre draws Antarctica with corners cut off its tiles.

## Look

The page is drawn as an ancient scroll: ink and red ochre on papyrus, with the timeline as a scroll unrolled across the foot of the page.

- Colors and type are the custom properties at the top of `src/styles.css`; the pigments for regions, categories and the map are in `src/theme.ts`, and the map's polity palette is in `src/lib/borders.ts` (baked into the border files, so re-run `npm run fetch-geo` after changing it).
- Type is Cinzel for headings and labels and Cormorant Garamond for reading text, bundled from the `@fontsource` packages. The map draws its labels from the Cinzel file through the style's `font-faces`.
- The map's language carries through the page: a wash of pigment inside an ink line. A state is a square bar, a period is a round-ended pill, a moment is a lozenge.
- A period is drawn once: in its row when its name fits, otherwise as a small labelled pill among the moments.
- The timeline's own surface is plain, without the papyrus texture, so that small lettering stays readable.
